# Coastal Wave–Rock Interaction

DH2323 project (KTH): storm waves hitting a sea cliff in Unity, with wave-break detection and foam that fades over time.

Blog: https://jing107999.github.io/CGProject_coastal-wave_blog/

## How to run

Open the `CoastalWaves` folder in Unity 6000.6.10f1 (URP), open `Assets/Scenes/Coastal.unity` and press Play.

Camera: right-drag to orbit, scroll to zoom, WASD + Q/E to move. P pauses, Space restarts, F switches debug views, H hides the overlay.

## Code

My scripts are in `CoastalWaves/Assets/Scripts/` and the shaders in `CoastalWaves/Assets/Shaders/`. The scripts I used for the measurements in the report are in `CoastalWaves/Assets/Editor/Experiments/`.

The textures in `Assets/Textures/ThirdParty/` are from Unity's Shader Graph samples (Unity Companion License).
